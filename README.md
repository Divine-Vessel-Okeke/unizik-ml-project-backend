## Setup Instructions

1. **Activate your virtual environment:**

   ```
   python3 -m venv .venv
   source .venv/bin/activate  # Linux/Mac
   # or .venv\Scripts\activate on Windows
   ```

2. **Install dependencies:**

   ```
   pip install -r requirements.txt
   ```

## Execution

1. **Start the API Server:**

   ```
   python app/main.py
   ```
